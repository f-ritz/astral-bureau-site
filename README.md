# The Astral Bureau — Website

Source for the independent esoteric consultancy website at **https://astralbureau.com**.

## Structure

- `index.html`: responsive single-page catalogue with services, method, about, FAQ, and availability notice
- `style.css`: responsive dark editorial design, no build pipeline or front-end framework
- `_headers`: original response-header policy (used by Pages; Worker behavior depends on asset routing)
- `.gitignore`: local and secret-file exclusions

## Deployment

The production site is deployed with **Cloudflare Workers static assets** from `main` through the Cloudflare Git integration. Wrangler configuration may be generated by Cloudflare when omitted.

No build command is required. Check Cloudflare's Workers & Pages dashboard for deploy status and custom domain routing.

## Business status

The site currently displays introductory reading packages at $17, $22, $35, and $53. These are a **catalogue preview**, not an operational ordering workflow. No backend, booking, payments, or client intake is implemented.

The page intentionally retains `<meta name="robots" content="noindex, nofollow">` until the owner approves public indexing.

## Before enabling orders

1. Confirm final service names, prices, fulfillment terms, and eligibility.
2. Configure a real business contact address or inquiry flow.
3. Publish privacy and terms policies appropriate for collecting birth dates and location details.
4. Set up verified scheduling, payment, and refund/cancellation terms.
5. Test client intake, accessibility, mobile layout, data handling, and domain routing.
6. Remove the `noindex, nofollow` directive when ready for discovery.

Do not commit client birth details, personal records, or secret API/payment credentials to the repository.
